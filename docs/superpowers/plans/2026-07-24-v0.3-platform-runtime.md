# v0.3 Platform Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install only selected capabilities and provide equivalent setup, hook, and doctor behavior on POSIX and Windows native.

**Architecture:** Keep one uv workspace. Derive both root extras and generated MCP entries from `FeatureSelection`, execute one selected sync, use thin `.sh`/`.cmd` launchers, and move Core hooks to Python/exec-form commands. Extend the doctor with JSON and opt-in live MCP probes.

**Tech Stack:** Python 3.13 stdlib, uv workspace extras, MCP Python SDK, pytest, GitHub Actions

## Global Constraints

- Core must not install camera, transcription, voice, X, or host-temperature packages.
- Tapo camera must not imply Whisper or faster-whisper.
- Windows native is a supported Core platform in `v0.3.0`.
- No Core Claude Code hook may require Bash, curl, jq, sed, or grep.
- Setup writes no secret to terminal output and preserves `.mcp.json` backup behavior.
- Doctor is read-only and live probes perform no outward hardware/social action.
